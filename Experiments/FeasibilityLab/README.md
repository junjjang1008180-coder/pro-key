# FeasibilityLab: 1단계 가능성 실험 앱

PRD 11절 마일스톤 1의 실험 세 가지를 확인하는 최소 앱입니다. 결과는 `PRD.md` 12절 표에 기록합니다.

| 타겟 | 역할 |
|---|---|
| `FeasibilityLab` | 메인 앱. 전면 카메라 프리뷰, 프레임 통계, 멀티태스킹 카메라 값, App Group 쓰기/읽기 |
| `LabKeyboard` | 키보드 확장. Full Access 상태, App Group 읽기/쓰기, 앱이 쓴 글 넣기 (카메라 코드 없음) |
| `Shared/` | 두 타겟 공유: App Group ID와 파일 입출력 |
| `Config/` | 키보드 Info.plist, 두 타겟의 entitlements (App Group 등록) |

## 처음 설치하기 (Xcode)

1. `FeasibilityLab.xcodeproj`를 더블클릭해 Xcode로 엽니다.
2. Apple 계정 추가: Xcode 메뉴 **Xcode > Settings… > Accounts** → 왼쪽 아래 **+** → **Apple Account** → 로그인.
3. 왼쪽 파일 목록 맨 위 파란 **FeasibilityLab** 아이콘 클릭 → 가운데 **TARGETS**에서 **FeasibilityLab** 선택 → **Signing & Capabilities** 탭 → **Team**에서 `(본인 이름) (Personal Team)` 선택.
4. **TARGETS**에서 **LabKeyboard**를 선택하고 3번과 같은 팀을 고릅니다.
5. iPad를 케이블로 연결 → iPad에서 **신뢰** → 암호 입력.
6. iPad에서 **설정 > 개인정보 보호 및 보안 > 개발자 모드** 켜기 → 재시동 → 다시 켜졌을 때 **켜기** 확인.
7. Xcode 위쪽 가운데 기기 선택 메뉴에서 본인 iPad 선택 → **▶︎(Run)** (⌘R).
8. 처음 실행 시 "신뢰할 수 없는 개발자"가 뜨면 iPad에서 **설정 > 일반 > VPN 및 기기 관리 > (본인 Apple 계정) > 신뢰**.

### 서명 오류가 날 때
- **App Group 관련 오류** (예: 무료 팀은 App Groups를 지원하지 않는다는 메시지): 실험 2의 결과입니다. 오류 문구를 그대로 복사해서 알려 주세요. 실험 1·3을 먼저 하려면 두 타겟의 **Signing & Capabilities**에서 **App Groups** 항목 옆 휴지통으로 임시 삭제하고 다시 실행합니다.
- **Bundle ID가 이미 사용 중**이라는 오류: `com.junjjang.PaperKeyboardLab`을 다른 이름으로 바꿔야 합니다. 직접 바꾸지 말고 알려 주세요 (App Group ID와 함께 여러 파일을 같이 고쳐야 함).

## iPad 설정 체크리스트
- [ ] 개발자 모드 켜기 (위 6번)
- [ ] 앱 첫 실행 → **카메라 시작** → 카메라 권한 **허용**
- [ ] **설정 > 일반 > 키보드 > 키보드 > 새로운 키보드 추가…** → **종이키보드 실험** 선택
- [ ] 같은 화면에서 **종이키보드 실험** 탭 → **전체 접근 허용** 켜기

## 실험 절차

### 실험 1: 멀티태스킹 카메라
1. 앱에서 **카메라 시작**. 표의 `isMultitaskingCameraAccessSupported` 값을 기록합니다.
2. 전체 화면에서 `초당 프레임`이 15 이상 나오는지 확인합니다.
3. 메모 앱과 함께 화면을 나눠 띄웁니다 (Split View, Slide Over, Stage Manager 중 iPadOS 26에서 되는 방식을 각각). 그 상태에서 실험 앱의 `초당 프레임`, `마지막 프레임 이후`, 아래 **기록**에 "⚠️ 카메라 중단"이 찍히는지 확인합니다.
4. 각 방식마다 창 크기, fps, 중단 메시지를 화면 캡처해서 보내 주세요.

판정: 화면을 나눈 상태에서도 fps가 유지되면 **모드 A 가능**, "멀티태스킹 중이라 카메라 사용 불가"가 뜨면 **모드 A 불가**.

### 실험 2: App Group
1. 앱의 실험 2 칸에서 `컨테이너: ✅ 열림`인지 확인합니다.
2. **App Group에 쓰기**를 누릅니다.
3. 메모 앱에서 새 메모를 열고, 키보드의 🌐를 길게 눌러 **종이키보드 실험**으로 바꿉니다.
4. 키보드에 "앱이 쓴 글: hello from app"이 보이면 **앱 글 넣기**를 눌러 메모에 입력되는지 확인합니다.
5. 키보드에서 **키보드→앱 쓰기**를 누른 뒤 실험 앱으로 돌아가 **키보드가 쓴 내용 읽기**를 누릅니다.
6. Full Access를 껐다 켜 보며 결과가 어떻게 달라지는지도 기록합니다.

### 실험 3: 거치 상태에서 종이와 손이 보이는지
1. 실제로 쓸 자세로 iPad를 거치하고 종이(또는 A4 용지)를 앞에 둡니다.
2. 앱의 프리뷰에서 종이 네 모서리와 검지 손가락 끝이 모두 보이는지 확인합니다. 카메라가 여러 개면 위쪽 선택 버튼으로 바꿔 봅니다.
3. 프리뷰 화면 캡처와 거치 모습 사진을 보내 주세요.
